# CuidaDor

Mobile application developed in 2025 as an academic project, focused on supporting people with osteoarthritis by providing tools for pain tracking and self-care practices.

## Features

- User registration and profile
- Pain intensity and location tracking
- 0–10 pain scale
- Guided exercises and stretching
- Breathing and relaxation techniques
- Educational content about osteoarthritis
- Reminders for practices and exercises
- Pain progression charts

## Technologies

- Dart / Kotlin
- C#
- REST API
- SQL Server

## Status

Academic project developed in 2025.

The application was deployed to a cloud environment using free-tier resources. The hosted version is no longer available, but the source code remains available in this repository for reference and documentation.
